# Airi Banquet Hall - Landing Page

A modern, responsive luxury wedding and event banquet hall landing page built with React, Vite, and Tailwind CSS.

## 🌟 Features

- **Hero Section**: High-impact visuals with booking CTA and key venue highlights.
- **Occasions & Events**: Tailored packages for weddings, corporate galas, and private celebrations.
- **Why Us**: Distinctive highlights, amenities, and capacities.
- **Gallery**: Curated photos of the venue, hall setups, and decor.
- **Location & Map**: Directions, venue address, and contact information.
- **Booking & Contact Form**: Inquiry form for reservations and pricing.
- **Cloudflare Tunnel Sharing**: Instantly share your local preview worldwide with `npm run share`.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nazik2020/Airi-Bunquet-Hall.git
   cd Airi-Bunquet-Hall
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Share local preview with clients/team via Cloudflare:
   ```bash
   npm run share
   ```

5. Build for production:
   ```bash
   npm run build
   ```

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React
- **Linter**: Oxlint
